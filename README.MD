# Парсер событий Прометей

`promethei_extractor` - библиотека и CLI-инструмент для сбора Событий (тестов, экзаменов, письменных работ)
с учебной платформы Прометей (МЭИ). Авторизуется по логину и паролю, собирает все События текущего семестра
по API, приводит их к единой нормализованной модели `pydantic` и либо сохраняет в `.json` (режим CLI), либо отдаёт
список Python-объектов (режим библиотеки) - для дальнейшей обработки модулями-потребителями (например,
генератором заметок в Obsidian или напоминалкой в Telegram).

## Требования

- [Python](https://www.python.org/downloads/latest/python3.12/) >= 3.12+
- аккаунт на образовательной платформе Прометей МЭИ (`dot.mpei.ac.ru`) - логин и пароль
- [uv](https://docs.astral.sh/uv/) >= 0.12.9
- `python` зависимости описаны в `pyproject.toml` и устанавливаются автоматически при выполнении `uv sync`

## Установка

### Как зависимость модуля-потребителя

Библиотека не публикуется в PyPI - устанавливается напрямую из репозитория:

```toml
# pyproject.toml проекта-потребителя
[project]
dependencies = [
    "promethei-extractor @ git+https://github.com/Spisocheg/promethei_extractor.git@TAG",
]
# при установке следует указать актуальную версию вместо TAG, например, "v1.0" (без ковычек)
```

или

```bash
uv add git+https://github.com/Spisocheg/promethei_extractor.git
```

### Как самостоятельный CLI-инструмент

```bash
git clone https://github.com/Spisocheg/promethei_extractor.git
cd promethei_extractor
uv sync
```

## Настройка

### Настройка переменных окружения

Создайте в корне проекта файл `.env ` - в нем будут храниться все чувствительные данные, требуемые для работы этого 
проекта. Создать его можно, например, выполнив в корне проекта следующую команду:

```bash
# Windows
echo '' > .env

# Linux
touch .env
```

Заполните файл `.env` следующими параметрами:

```dotenv
PROMETHEI_LOGIN=ваш_логин
PROMETHEI_PASS=ваш_пароль
OUTPUT_DIR=путь_до_папки_куда_выгрузить_список_событий
```

Без валидных значений (пустом или отсутствующем `.env`) приложение не запустится.

`OUTPUT_DIR` является опциональным. Если он не указан, а экстрактор запущен в cli-режиме, выходной файл будет сохранен 
в папке, откуда приложение запущено. 

## Использование

### CLI-режим

```bash
uv run promethei-extractor
```

По умолчанию собранные События сохраняются в файл `Promethei Events {YYYY-MM-DD}.json` в текущей рабочей
директории. Уровень логов по умолчанию - `INFO`; подробный вывод (в т.ч. отладочная информация о разборе
XML-ответов) включается флагом `--debug`:

```bash
uv run promethei-extractor --debug
```

### Как библиотека

```python
from promethei_extractor import get_events
from promethei_extractor.exceptions import ExtractorError, AuthenticationError

try:
    events = get_events()
except ExtractorError as e:
    ...     # рекомендуется запуск в конструкции try-except для отлова возникающих при экстракции событий и предприятия действий
```

`get_events()` возвращает `list[Event]` - типизированные модели `pydantic`, без побочных эффектов записи на диск.

#### Логирование

Логи модулей `parser` и `normalize`, а также самой библиотеки, **выключены по умолчанию** - при импорте
`promethei_extractor` не выведет ничего, пока модуль-потребитель не включит их явно:

```python
from loguru import logger

logger.enable("promethei_extractor")
```

(В CLI-режиме логи включаются автоматически - `cli.py` делает это самостоятельно при запуске)

## Описание функционирования

### Пайплайн выполнения

1. запрос на api с данными пользователя
2. получение cookie сессии
3. запросы с куки на получение ивентов (итерация query-параметров месяц и год в рамках обрабатываемого семестра)
4. получение ответов на запросы и преобразование в xml
5. нормализация данных: преобразование в модель, валидация, дедупликация
6. возврат экстрактором списка событий

### Обработка ошибок

Все ошибки библиотеки - наследники `ExtractorError` (`promethei_extractor.exceptions`), его достаточно
ловить, если детализация не нужна:

| Исключение               | Когда возникает                                                              |
|---------------------------|-------------------------------------------------------------------------------|
| `ConfigurationError`      | не заданы логин/пароль или `.env` отсутствует/некорректен                    |
| `AuthenticationError`     | Прометей не выдал куки сессии (неверный логин или пароль)                    |
| `PrometheiApiError`       | сетевая ошибка при обращении к Прометею (таймаут, обрыв соединения)          |
| `MalformedResponseError`  | ответ Прометея не удалось разобрать как XML даже с восстановлением           |
| `OutputWriteError`        | не удалось записать результат на диск (только CLI-режим)                     |

Отдельные События, не прошедшие нормализацию (отсутствуют обязательные поля, невалидные значения), не
останавливают весь запуск - они пропускаются с предупреждением в лог.

### Формат данных

`pydantic`-описание модели `Event`:

```python
class Course(BaseModel):
    id_: UUID
    name: str

class Event(BaseModel):
    id_: UUID           # ключ дедупликации в рамках одного запуска
    name: str
    type_: str          # сырой код подтипа События от Прометея (eventSubType); маппинг в человекочитаемый вид не выведен
    str_type: str       # человекочитаемый тип, определяется по названию События
    date_start: date
    date_end: date
    course: Course
```

Дамп `Event` в `json` (записывается в `.json` в cli-режиме):

```json
[
  {
    "id_": "3a4c1ce6-accd-49d2-81f5-1fc27580951b",
    "name": "КМ-1. Дифференциальные уравнения 1-го порядка",
    "type_": "4",
    "str_type": "Тестирование",
    "date_start": "2026-09-19",
    "date_end": "2026-09-25",
    "course": {
      "id_": "0461bce1-27af-4576-afeb-f21eece81502",
      "name": "Дифференциальные уравнения"
    }
  },
  ...
]
```

## Структура проекта

```text
promethei_extractor/
├── src/
│   └── promethei_extractor/
│       ├── __init__.py         # публичный интерфейс: get_events
│       ├── pipeline.py         # оркестрация: parser → normalize
│       ├── parser.py           # сбор сырых данных с API Прометея
│       ├── normalize.py        # сырые данные → list[Event]
│       ├── models.py           # Event, Course, Date (pydantic)
│       ├── settings.py         # конфигурация (.env), инициализация логов
│       ├── exceptions.py       # ExtractorError и наследники
│       ├── constants.py        # url'ы, маппинги — неизменяемые значения
│       └── cli.py              # точка входа: команда promethei-extractor
├── techspec.md                 # полное ТЗ — контракты API, модели, бизнес-правила
├── pyproject.toml
└── .env                        # не коммитится
```
